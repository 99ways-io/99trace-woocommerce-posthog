# Code of conduct

99Trace follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, keep discussions about the work, and never harass anyone.

Report unacceptable behaviour to the maintainers at 99Ways through [99ways.io/contact](https://99ways.io/contact/). Reports are handled confidentially, and the maintainers may remove comments, commits or contributors that break this code.
